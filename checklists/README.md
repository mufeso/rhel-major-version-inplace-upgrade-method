# Checklists

items marked *(example)* are typical but not universal.

| Checklist | Used when |
|-----------|-----------|
| [pre-flight.md](pre-flight.md) | Days or weeks before the change window |
| [go-no-go.md](go-no-go.md) | At the start of the change window, per batch |
| [post-upgrade-validation.md](post-upgrade-validation.md) | Before handing a server to the application owners |
| [rollback-decision.md](rollback-decision.md) | When the application owners report a problem after testing |
